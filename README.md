# 🪈 Radha Krishna 3D Wedding Experience

A cinematic 3D web experience built with **Three.js** and **Vite**, featuring a sacred bansuri (flute) fly-through, celestial stardust streams, volumetric light shafts, and a blooming lotus reveal of Radha & Krishna.

## ✨ Features

- **Realistic Bansuri Craftsmanship**: Procedurally textured bamboo with natural growth nodes, micro-fibrous bump mapping, authentic wall thickness, flame-burnished finger holes, and red silk thread bindings with gold zari accents.
- **Volumetric Light Shafts**: 7 divine columns of sunlight streaming through the flute finger holes.
- **Musical Particle Vortex**: Delicate glowing musical notes (`♪`, `♫`, `✦`, `♬`) and 360 celestial stardust motes swirling gracefully into and through the flute bore.
- **Inner Sacred Architecture**: Perspective resonance rings, double-helix golden energy filigree, and a distant golden sun portal.
- **Responsive Design**: Built for mobile phones (iOS & Android with notch / safe-area support), tablets, and high-res laptop displays with dynamic aspect-ratio FOV adjustments.
- **Interactive Details Drawer**: Smooth slide-out panel with wedding itinerary and RSVP.

## 🛠️ Tech Stack

- **Three.js**: WebGL 3D scene, materials, lighting, cameras, and particle systems.
- **Vite**: Ultra-fast development and optimized production bundling.
- **Vanilla CSS**: Fluid typography, responsive safe-area insets, and glassmorphism.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/NandaKishorekandregula/radha-krishna-threejs.git
cd radha-krishna-threejs

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
